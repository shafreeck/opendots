# 验收与证据矩阵

更新：2026-09-30。当前不是完整复刻或生产就绪声明。历史模拟骨架记录仅见 TEST_REPORT.md；当前证据见 RUNTIME_VALIDATION.md、LONG_TOOL_VALIDATION.md、COMPUTER_EDGE.md。状态随真实验证推进，不以测试数量替代用户可见结果。

## 验证层级

- **L1**：真实产品代码的单元、HTTP/WS、数据库与故障注入测试；外部协议可能是受控替身
- **L2**：未修改的真实 Morphz Runtime + 确定性本地模型协议服务；可验证原生调度、工具、事件、权限及产品接线，但不验证自然语言能力
- **L3**：用户授权的真实模型 + 有界真实任务/工具结果；需要安全配置模型及明确使用范围
- **L4**：真实浏览器画面、输入、设备、外部渠道或完整客户端；不能用静态审阅、合成截图或协议测试替代

## 发布前剩余门禁

1. L3真实模型以及选定目标上的L4电脑/客户端验证
2. 新登录、连接器与真实外部投递的权限、撤销、审计及恢复验证
3. 备份/迁移/回退、资源上限、长时间运行和依赖/SBOM/许可证复核
4. 公开部署前完整身份/TLS、隔离与服务边界验收，不能直接公开当前loopback BFF
5. 用户确定GitHub账户、仓库、可见性和原创代码许可证；获得发布授权后再操作

Morphz Runtime代码保持原样。用户已说明不需要重复测试Morphz自身沙箱；显式full_access仅用于隔离、固定命令的产品并发测试，不改产品默认权限，也不替代实际电脑隔离验收。未执行、失败或仅静态审阅的项目不得标记为通过。
