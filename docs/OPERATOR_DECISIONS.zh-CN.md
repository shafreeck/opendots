# 接下来需要确定的配置与交付选择

以下选择影响真实环境验收或对外发布。当前代码、协议测试和本地构建产物不能替代这些配置；密钥不应放入聊天、Git 或前端构建。

1. **实际运行在哪里**：先选择本机或专用 VPS，再确定 HTTPS 域名与代理。产品仍连接本机 Morphz；移动端需要真实可达的 HTTPS 入口。既有认证数据库绑定的来源地址不能自动改写。见 [远程入口](REMOTE_TRANSPORT.md) 和 [电脑配置](COMPUTER_CONFIG.md)
2. **真实模型如何验证**：用户通过 BYOK 设置自行配置/选择 Morphz 账户与模型，再确定一次有界任务和使用额度。共享 Runtime 的全局模型选择可能影响其他继承默认值的会话，建议独立实例。保存配置不会自动消耗推理额度
3. **先验收哪些实际设备**：选择实际桌面/浏览器以及 Android 或 iOS 设备。当前已有客户端源码和移动端 JavaScript 构建，尚无 APK/IPA、签名或实际设备验收。SDK、签名身份与分发方式另行确定。见 [桌面客户端](DESKTOP_CLIENT.md) 和 [移动客户端](../apps/mobile/README.md)
4. **是否启用真实语音**：语音服务与对话模型分别配置。现有提供商支持单次语音及流式听写，能力明确为 `duplex:false`。实际麦克风与供应商调用需要用户主动同意音频传输与可能费用；全双工通话还需要合适的已支持提供商能力，不能把听写循环当作通话
5. **需要连接或投递到哪里**：私有账户、OAuth 应用、事件来源、外部通知目的地和文件分享对象尚未选择。现有应用内通知、公开只读工具与本地文档版本不代表已授权外部发送、分享或建立账户访问
6. **将来如何发布**：确定 GitHub 账户、仓库、可见性和原创代码许可证，再处理签名/部署/发布。当前没有推送、公开部署或源码包交付；第三方依赖许可证、已记录的移动端依赖警告以及恢复工具未完成的独立审阅仍需关闭

当前完整进度与证据见 [STATUS](STATUS.md)、[ACCEPTANCE](ACCEPTANCE.md) 和 [VALIDATION_CURRENT](VALIDATION_CURRENT.md)。这些选择不阻止已授权且不依赖账户、设备或外部发布的工程工作继续。
